\# Documento de Identidade Visual – Nightfall

\*\*Projeto:\*\* Nightfall – Hub de Minijogos    
\*\*Disciplina:\*\* Desenvolvimento Web / Projeto Integrador

\---

\#\# Identidade Visual

O \*\*Nightfall\*\* é um hub de jogos desenvolvido com uma identidade visual inspirada na estética gótica minimalista, utilizando elementos sombrios, elegantes e discretos. O objetivo é transmitir uma atmosfera melancólica e imersiva, mantendo uma interface limpa, consistente e de fácil navegação.

\#\# Diretrizes Visuais

\- Interface baseada em uma estética gótica minimalista.  
\- Utilização predominante de tons escuros para proporcionar contraste e conforto visual.  
\- Branco utilizado para garantir contraste e legibilidade, enquanto a cor de apoio (\`\#800000\`) é aplicada em estados de interação, seleção e feedback visual.  
\- Layout padronizado entre todas as páginas do sistema, garantindo consistência visual.  
\- Componentes reutilizáveis para manter uniformidade na experiência do usuário.

\---

\#\# Conclusão

A identidade visual do \*\*Nightfall\*\* foi definida para assegurar padronização em todas as páginas do projeto. A adoção de uma paleta de cores consistente, tipografia unificada e componentes reutilizáveis contribui para uma interface coesa, moderna e alinhada à proposta temática do jogo.
